# Keyboard shortcuts

| Action                         | Shortcut                |
| ------------------------------ | ----------------------- |
| Create a checkpoint            | `Ctrl/Cmd` + `N`        |
| Focus timeline search          | `Ctrl/Cmd` + `K` or `/` |
| Open the timeline              | `G`, then `T`           |
| Close a dialog or detail panel | `Escape`                |

Shortcuts do not fire while a text field is handling the same key for editing. Every action remains
available through a labeled button or navigation control.
