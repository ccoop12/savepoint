Privacy is an architectural constraint

Your repository never leaves your machine.

SavePoint has no account system, cloud backend, telemetry, ads, or paid API. It stores structured context and Git metadata in a local database. Source contents, complete diffs, shell history, clipboard data, and environment variables are out of scope by design.

Built like a desktop tool should be

A narrow trust boundary.
A boring, dependable stack.

InterfaceReact + TypeScript→Trust boundaryValidated IPC→Local servicesGit + SQLite

Electron runs with context isolation enabled and Node integration disabled in the renderer.

Git capture uses a temporary config-isolated view, so repository hooks, filters, diff drivers, and submodule commands cannot execute. The capture and filtering logic stays independently testable.

Checkpoints use migrations, foreign keys, runtime schemas, and deterministic metadata fingerprints.
